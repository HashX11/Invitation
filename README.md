# Samah & Zeina — عقد قران

An animated Arabic invitation for Samah Al Qadi and Zeina Bakri. Open the wax-sealed letter, explore the layered garden and moving fountain, then scroll through the Quran verses, family invitation, date, venue, and practical links. The original music is included.

**Live invitation:** https://sameh-zeina-garden-invitation.hashemx11.chatgpt.site/

The root `index.html` is a self-contained version suitable for GitHub Pages or any static host. It includes the artwork, fonts, music, and calendar file, so it also works without a build step. The editable React and CSS source is in `app/`; source artwork, fonts, audio, and calendar data are in `public/`.

To rebuild the self-contained page, install dependencies and run `npm run build` (Node.js 22 or later).

The invitation supports a personalized guest name with `?to=Guest%20Name`.
