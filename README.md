# Sameh & Zeina — عقد قران

An animated Arabic invitation for Sameh Al Qadi and Zeina Bakri. Open the wax-sealed letter, explore the layered garden and moving fountain, then scroll through the Quran verses, family invitation, date, venue, and directions. The original music is included.

**Guest invitation:** https://hashx11.github.io/Invitation/

The root `index.html` is a self-contained version suitable for GitHub Pages or any static host. It includes the artwork, fonts, and music, so it works without a build step. The editable React and CSS source is in `app/`; source artwork, fonts, and audio are in `public/`.

To rebuild the self-contained page, install dependencies and run `npm run build` (Node.js 22 or later).

The invitation supports a personalized guest name with `?to=Guest%20Name`.
