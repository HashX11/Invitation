# Sameh & Zeina — عقد قران

A scrollable Arabic wedding invitation with a wax-sealed letter, layered garden, moving birds and fountain, animated cars, music, map directions, and a calendar download.

**Guest invitation:** https://hashx11.github.io/Invitation/

The root `index.html`, `style.css`, and `script.js` are the live GitHub Pages source. They use the original artwork, fonts, music, and calendar file under `public/`. Edit those files directly. Run `npm run build` to syntax-check the JavaScript. The older React prototype remains in `app/` for reference and does not produce the live page.
